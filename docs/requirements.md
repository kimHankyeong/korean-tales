# Korean Tales 게임 개발 요구사항 정리

> 기획서 원문을 기능 단위로 분해해 클로드 코드에 입력하기 쉬운 형태로 재구성했습니다.
> 미확정 사항은 맨 아래 "결정 필요 사항"에 따로 모아뒀습니다.

---

## 1. 방(로비) 설정 기능

- [ ] 인원수 모드: **7인 모드 / 9인 모드** 선택 가능한 방 생성 UI
- [ ] 개인 발언시간 옵션: **80초 / 120초** 중 방장이 선택
- [ ] 전체 토론시간 옵션: **3분 / 5분** 중 방장이 선택
- [ ] **준비(레디) 시스템**: 각 플레이어가 준비 버튼을 토글. 정원 미달 상태에서도 준비는 가능하나,
      **방 설정의 인원수(7/9)가 정확히 다 차고 전원이 준비를 누른 순간 자동으로 게임이 시작**된다
      (별도의 방장 "게임 시작" 버튼 클릭 불필요). 인원이 새로 들어오거나 방 설정(인원수·타이머)이
      바뀌면 전원의 준비 상태는 초기화된다
- [ ] **관리자 정원 미달 시작**: `ADMIN_EMAILS` 환경변수(쉼표 구분 이메일 목록)에 등록된 계정으로 로그인한 방장은, 봇 없이 실제 참여 인원만으로(1명 이상이면) 정원 미달 상태에서도 게임을 시작할 수 있다 — 혼자 테스트용. 남은 슬롯은 존재하지 않는 상태로 진행되며, 캐릭터는 해당 모드 로스터 중 무작위 일부만 배정된다
  - **직업 선택**: 관리자가 이 방식으로 시작할 때는 본인이 플레이할 직업을 직접 골라 확정 배정받을 수 있다(원하면 "무작위 배정"도 선택 가능) — 특정 캐릭터의 스킬을 집중적으로 테스트할 때 사용. 일반 유저가 직업 지정을 보내도 서버가 무시한다(관리자 전용)
  - **가상 플레이어로 정원 채우기**: 관리자는 남은 정원을 실제 계정 없는 가상 플레이어로 채워 시작할 수도 있다. 가상 플레이어는 스스로 행동하지 않으며, 관리자가 게임 화면의 "가상 플레이어 조작" 패널에서 각 가상 플레이어의 입장으로 전환해 투표·발언 스킵·기권·스킬 사용(대상 지정 포함)을 매 순간 직접 대신 지정해야 진행된다(자동 패스 없음). 가상 플레이어는 게임이 끝나면 로비에서 자동으로 제거된다
- [ ] 개인 발언 중 **Skip 버튼**: 본인 발언 종료 시 다음 순서로 즉시 넘김
- [ ] 전체 토론 중 **Skip 시스템**: 생존자 전원이 skip을 누르면 토론 종료 → 투표 단계로 자동 전환
- [ ] **강퇴 기능**: 대기방(게임 시작 전)에서 방장은 다른 플레이어를 강퇴할 수 있다. 플레이어 목록에서 해당 플레이어 오른쪽의 "⋯" 버튼을 누르면 "강퇴" 버튼이 나타나고, 누르면 즉시 방에서 제거된다. 강퇴당한 사람은 로비로 강제 이동한다. 게임이 시작된 뒤에는 강퇴할 수 없다
- [ ] **새로고침·재접속 복구(로그인 유저 한정)**: 로그인 유저는 소켓 신원이 계정 id로 고정되므로,
      새로고침 등으로 소켓이 끊겼다 다시 붙어도 같은 사람으로 인식된다. 대기방에서 끊기면 30초
      유예 후에도 재접속하지 않을 때만 실제로 방에서 제거되고(그 사이 재접속하면 그대로 유지),
      게임 중에는 끊긴 인원을 즉시 제거하지 않으며 재접속 시 현재 방/게임 상태를 그대로 이어서
      복구한다(직업·페이즈·남은 시간 등). 게스트(비로그인)는 재접속 복구 대상이 아니다.

---
6인모드가 아니라 7인 모드 체제로 변경, 저승사자, 구미호, 해태, 도깨비, 바리공주, 자청비, 장화홍련, 조언자 뽑기 제외하고 스킬, 승리 조건은 9인모드와 동일.

## 3. 캐릭터 & 스킬 시스템

공통: 각 캐릭터는 배경설화(1~2줄) + 스킬 설명을 **스킬북 UI**에 함께 표시.

### 악 진영
| 캐릭터 | 스킬명 | 효과 | 비고 |
|---|---|---|---|
| 저승사자 | 사자의 명부 (2회) | 전날 밤 미리 길동무 1인 지정 → 투표·처형 등으로 자신이 사망 시 지정한 사람과 함께 죽음. 2회 지정 후에도 사망하지 않았다면 스킬 종료 | 기존 "저승길 동무"에서 개명 — 예전에 "사자의 명부"라는 이름은 다른 메커니즘(예고킬)에 쓰였다가 밸런스 사유로 교체됐던 것을 현재의 길동무 메커니즘 이름으로 재사용. 죽은 자를 저승으로 인도하는 본연의 설화와 부합 |
| 깡철이 | 재앙무죄 (패시브) | 해태의 투사에 **"악 진영이 아닙니다"**로 표시됨. 별도 발동 절차 없음 | 배경설화: 용이 되지 못하고 추락한 이무기. 지나는 하늘 아래는 비가 마름. 재앙에는 죄를 물을 수 없기에 해태의 심판이 닿지 않음 |
| 구미호 | 유혹 (1회) | 전날 밤 사용 여부 결정 → 다음날 낮 투표를 통째로 스킵 | 조사 회피 능력은 깡철이로 이전, 투표 스킵만 보유 |

### 선 진영
| 캐릭터 | 스킬명 | 효과 | 비고 |
|---|---|---|---|
| 자청비 | 부활꽃 / 멸망꽃 (각 1회) | **아침에 사용.** 부활꽃: **그날 밤 악 진영의 킬로 사망한 사람만** 되살릴 수 있음(치유). 멸망꽃: 1인을 즉시 처형. 각각 게임당 1회씩, **같은 아침에 두 꽃 동시 사용 불가** | 부활꽃 제외 대상: 사자의 명부·피 맺힌 유서로 동반 사망한 사람, 낮 투표 처형자. 멸망꽃 킬은 도깨비 장난으로 막을 수 없고, 멸망꽃 사망자는 동귀어진류 스킬 사용 불가 |
| 해태 | 투사 | **밤마다 1회** 1인 지목 → **"n번은 악 진영입니다 / 악 진영이 아닙니다"** 형식으로 해태 본인 화면 중앙에 4초간 표시(해태 본인에게만 — 정보 은닉). 단, 깡철이는 "악 진영이 아닙니다"로 표시됨 | ✅ **확정(고정) — 변경하지 않음** |
| 도깨비 | 도깨비 장난 (보호 성공 전까지 무제한) | **매일 밤 보호할 생존자 1인 지정.** 그날 밤 악 진영의 킬 대상이 보호 대상과 같으면 그 사람은 죽지 않음(보호 성공). 단, 아침의 자청비 멸망꽃 킬은 막지 못함 | 보호에 **한 번이라도 성공하면 이후 스킬 사용 불가.** 성공한 적 없다면 매일 밤 대상을 다시 지정해 재사용 가능. 악 진영의 처치 투표는 그대로 진행하되, 보호 성공 여부와 무관하게 차단 사실은 공개하지 않음 (다음날 아침 "사망자 없음"으로만 표시) |
| 장화홍련 | 피 맺힌 유서 (1회) | **자신의 사망이 확정된 시점**에 1인을 지목해 함께 데려감(동귀어진). 15초 내 미선택 시 자동 포기, "스킬 포기" 버튼으로도 포기 가능 | 자청비의 멸망꽃으로 사망한 경우 스킬 사용 불가 |

### 중립
| 캐릭터 | 스킬명 | 효과 |
|---|---|---|
| 바리공주 | 연민 (자동 발동) | **까치선비가 어떤 방식으로 사망하든** 부활 가능 — 사자의 명부·피 맺힌 유서 동반사망 등 자청비 부활꽃이 닿지 않는 죽음에도 예외적으로 적용. 낮 사망이면 당일 아침, 그 외에는 다음날 아침 자동 부활 |
| 까치선비 | 없음 | 선 진영 소속 중 사망하면 중립 전환. 바리공주 생존 시 부활 대상이 됨 |
중립 진여의 승리조건: 선 진영의 승리 조건과 동일==중립 진영이 1명이상 생존, 악 진영 모두 처형

- [ ] **부활자 공통 규칙**: 부활꽃·연민으로 되살아난 사람이 이미 사용한 1회성 스킬은 **소모된 상태로 유지**(복구되지 않음)

## 4. 밤 페이즈 진행 로직

- [ ] **게임은 항상 밤(밤 0)부터 시작한다.** 방장이 게임을 시작하면 조언자 선출(9인 모드)이나
      낮 개인 발언(7인 모드)보다 먼저 아래 밤 사이클이 한 차례 진행되고, 그 밤이 끝난 뒤에야
      9인 모드는 조언자 선출로, 7인 모드는 곧장 낮 개인 발언으로 이어진다. 이후의 모든 밤은
      평소처럼 낮 다음에 온다 — 밤이 먼저 오는 건 게임 시작 시 딱 한 번뿐이다.

밤 내부 순서(13번 피드백으로 악 진영을 먼저 배치했던 순서를 유지하되, 자청비는 해태·도깨비와
같은 타이밍으로 통합함 — 아래 참고):
1. 악 진영 토론 (90초)
2. 악 진영 처치 대상 투표 (15초) — 이 시점에 그날 밤의 "킬 대상"이 내부적으로 확정된다
3. 악 진영 개별 스킬 시간 (15초, 투표 후 순차 또는 동시)
   - 저승사자: 사망 시 데려갈 길동무 선택 (사자의 명부)
   - 구미호: 다음날 낮 투표 스킵 사용 여부 결정 (유혹)
   - 깡철이: 패시브라 선택 절차 없음
4. 해태 / 도깨비 / **자청비** 스킬 사용 시간 (10초, 동시 진행) — 자청비는 2번에서 확정된 "그날 밤
   킬 대상"을 대상으로 부활꽃/멸망꽃을 고른다. **이 시점에는 아직 도깨비가 그 대상을 보호할지
   알 수 없다** — 즉 자청비는 도깨비의 보호 성공 여부를 모른 채 선택한다(도깨비 스킬과 겹칠 수
   있음을 감수)
   - 부활꽃: 그날 밤 악 진영의 킬 대상이 있을 때만 활성화, 그 대상 지정 부활만 가능(동반사망자·
     투표 처형자는애초에 후보가 아님 — 밤 킬 대상 한 명만 후보)
   - 멸망꽃: 생존자 1인 지정 즉시 처형 (도깨비 장난으로 방어 불가). 대상 선택창 상단에
     **"멸망꽃으로 누구를 죽이시겠습니까?"** 문구 표시
   - 같은 밤에 둘 다 사용 불가 (하나 선택 시 다른 쪽 비활성화)
5. 새벽 판정 — 4번에서 각자 고른 선택을 한꺼번에 반영해 그날 밤의 실제 사망 여부를 확정한다.
   - 도깨비가 지정한 보호 대상이 악 진영의 킬 대상과 같으면 → 킬 결과 무효(보호 성공 — 이후 도깨비
     장난 재사용 불가로 전환). **악 진영에게 차단 사실을 따로 알리지 않으며**, 다음날 아침 전체에게
     "사망자 없음"으로만 표시
   - 자청비가 부활꽃을 킬 대상에게 사용했다면 → 킬 결과 무효, 부활꽃 소모
   - **도깨비 보호와 자청비 부활꽃이 같은 대상(그날 밤 킬 대상)에 동시에 쓰인 경우**: 결과적으로
     한쪽만으로도 이미 생존했겠지만, **둘 다 소모된 것으로 처리**한다(4번 시점에 서로의 선택을 모른
     채 각자 판단했으므로)
   - 위 두 경우 모두 아니면 킬은 그대로 적용되며, 도깨비는 다음 밤에도 보호 대상을 다시 지정할 수
     있다
- [ ] **밤 채팅**: 밤에는 전체 공개 채팅을 아무도 쓸 수 없다(낮 토론에 대응하는 밤 전체 토론이 없으므로). 악 진영 생존자는 악 진영 전용 채널로만 밤 토론(2번)을 진행하며, 그 채널은 악 진영 생존자에게만 중계된다. 이 악 진영 전용 채널은 낮 공개 채팅과 헷갈리지 않도록 채팅창 헤더에 별도 표시(예: "악 진영 전용 채널" 배지 + 테두리 색 구분)를 준다
- [ ] **밤 사망의 아침 공개**: 4번(스킬 시간)~5번(새벽 판정) 동안 실제로 죽을 사람이 내부적으로
      확정되더라도, 그 사망 사실은 **낮이 시작되어 공식 발표될 때까지 다른 플레이어에게 노출되지
      않는다** — 밤 진행 중 어떤 스냅샷에서도 그날 밤 사망자의 프로필이 미리 어두워지거나 죽은
      것으로 표시되면 안 된다.

## 5. 낮 페이즈 진행 로직

> 자청비 부활꽃/멸망꽃 선택은 4번 섹션(밤)으로 이동했다 — 낮은 이제 개인 발언부터 시작한다.

1. 구미호가 전날 밤 "유혹"을 사용했다면: 낮 토론 후 투표 단계 전체 스킵 → 바로 밤 전환. 스킵되는 순간 방 전체 화면 중앙에 **"구미호에 홀려 아무도 투표를 할 수 없게 되었다"**를 3초간 표시
2. 낮 토론 (전체 토론시간 옵션에 따름)
3. 투표 진행 — **생존자 전원이 투표를 마치면 제한시간(15초)을 다 기다리지 않고 즉시 다음 단계(결과 공개)로 진행**
   - **기권 규칙**: 투표권을 가진 생존자 전원이 기권하면 희생자 없이 밤으로 전환. 단 한 표라도 득표자가 있으면 최다 득표자가 처형됨 (기권표가 다수여도 무관)
   - **동표 처리**: 최다 득표가 동률이면 → 최다득표자 전원에게 동시 발언 시간 20초 부여 → 재투표 진행(재투표도 전원 투표 완료 시 즉시 진행) → 재투표에서도 동표면 최다득표자 중 **무작위 1인 처형**
4. **최후의 변론 (20초)**: 투표로 처형 대상이 확정되면 그 사람에게만 채팅 입력 권한 부여, 나머지는 관전. **처형 대상자 본인만** Skip 버튼으로 조기 종료 가능
5. 사망 확정 트리거 (투표·멸망꽃 등 사망 발생 시 공통 처리):
   - 저승사자 사망 시: 지정해둔 길동무와 동반 사망 → 결과 표시 후 프로필 변경 전 저승사자 전용 사망 이펙트 재생 (**단, 자청비의 멸망꽃으로 사망한 경우, 또는 장화홍련의 피 맺힌 유서에 지목되어 동반 사망한 경우 길동무 동반 사망은 발동하지 않는다**). 동반 사망이 확정되는 순간 방 전체 화면 중앙에 **"저승사자가 사자의 명부에 n번을 적었습니다"**를 4초간 표시
   - 장화홍련 사망 시: "피 맺힌 유서" 대상 선택창 15초 표시 (**멸망꽃 사망이거나, 저승사자의 길동무로 지목되어 동반 사망한 경우 미표시**). 대상을 지목하면 방 전체 화면 중앙에 **"유서에 쓰인 건 n번입니다"**를 4초간 표시
   - 조언자 사망 시: 승계 지목 / 파기 선택창 10초 표시
   - 까치선비 사망 시: 바리공주 생존 중이면 "연민" 자동 부활 예약 (사망 원인 불문)

## 6. UI/UX 요구사항

- [ ] **사망자는 관전만 가능**: 죽은 플레이어는 투표·스킬 사용·(본인의 사망 확정 트리거 응답 제외) 어떤 행동 프롬프트도 화면에 뜨지 않는다. 서버는 원래도 사망자의 행동을 가드에서 거부하고 있었지만(투표·스킬 등 모든 액션이 행위자 생존 여부를 검증), 클라이언트가 사망 여부와 무관하게 프롬프트를 계속 띄워주고 있어 "눌러도 반응이 없다"처럼 보이는 문제가 있었다 — 클라이언트도 사망 여부를 확인해 프롬프트 자체를 숨긴다
- [ ] **낮 표시 애니메이션**: 해 모양 아이콘이 나타났다가 채팅창의 "낮" 텍스트 옆으로 이동/고정
- [ ] **발언 순서 표시 포맷**: `(해)낮-개인발언시간-1번` 형태로 채팅창에 표시. 개인 발언 시간에는 그 차례인 사람만 채팅 입력 가능(최후의 변론과 동일한 단독 발언 메커니즘), 나머지는 관전
- [ ] **채팅 발신자 표시**: 채팅창에서 발신자는 `n번.닉네임` 형태로 배정 번호와 함께 표시한다 (예: `5번.바우`)
- [ ] **카운트다운 표시**: `토론 시간 00초 남음` / `개인 발언 시간 00초 남음` 문구
- [ ] **Skip/단발성 스킬 버튼 클릭 피드백**: 눌렀다는 걸 알 수 있도록 버튼 채도를 낮추고 비활성화한다(전체 토론 skip은 생존자 전원이 눌러야 조기 종료되므로, 내 클릭이 반영됐는지 시각적으로 알려줄 필요가 있음). 새 발언 차례·페이즈로 넘어가면 다시 누를 수 있게 초기화
- [ ] **투표 창**: 화면 중앙, 화면 1/6 크기, 생존 플레이어 번호+프로필 가로 나열. 프로필 클릭 → 하단 "투표하기" 버튼 활성화. **기권 옵션 포함**
- [ ] **스킬 사용 창**: 투표 창과 동일 레이아웃, 버튼만 "선택하기"로 대체 (대상: 해태, 도깨비, 자청비, 저승사자, 장화홍련(사망 시) 등. 장화홍련 창에는 "스킬 포기" 버튼 추가)
- [ ] **메모장**
  - 모바일: 채팅창 뒤에 숨겨져 있다가 클릭 시 앞으로 슬라이드
  - PC: 채팅창 옆에 상시 노출 (동시 열람 가능)
- [ ] **직업 설명 버튼** (우측 상단): 클릭 시 9개 캐릭터 스킬북 + 진영별 승리 조건 표시
- [ ] **플레이어 목록 패널** (우측): 화면 1/6 크기, 프로필 + 배정 번호 표시
  - **추측 직업 아이콘**: 본인을 제외한 각 프로필 사진 옆에 내가 추측한 직업을 이모지로 메모할 수 있다. 별도의 고정 아이콘 세트를 만들지 않고 기기 키보드(모바일 이모지 키보드·데스크톱 OS 이모지 입력)로 자유 입력하게 한다 — 자체 아이콘 세트보다 개발 비용이 훨씬 낮고, 정해진 캐릭터 목록에 얽매이지 않는 자유로운 추리 메모가 가능하다. 서버로 전송하지 않는 순수 클라이언트 로컬 상태이며 새 게임 시작 시 초기화된다
  - **닉네임 축약**: 좁은 칸에서 줄바꿈되지 않도록 4글자를 넘는 닉네임은 `"..."`으로 축약해 표시한다 (예: `불닭볶음...`)
  - **세로 모드 모바일 레이아웃**: 채팅창이 지나치게 좁아지지 않도록, 세로 모드(휴대폰 세로 폭)에서는 프로필을 세로 한 줄이 아니라 **2열 그리드**로 압축 표시한다(7~9명이 2×4~2×5면 한 화면에 들어옴). 가로 모드·데스크톱에서는 기존처럼 세로 목록 유지
- [ ] **모바일 가로 모드 지원**: 좁은 화면에서도 기기를 가로로 돌리면(휴대폰 세로 폭이 데스크톱 분기점보다 좁아도) 채팅창·플레이어 목록·사이드바가 데스크톱과 동일하게 가로로 배치되도록 한다(`landscape:` 방향 기준 — 폭 기준 분기점만으로는 세로가 짧은 가로 모드에서 레이아웃이 깨짐). 그래도 다 안 들어갈 만큼 좁으면(작은 폰 가로) 줄어들다 찌그러지는 대신 좌우 스크롤로 넘겨볼 수 있게 한다
- [ ] **모바일 채팅창 크기**: 세로 모드에서는 채팅창 높이를 화면의 약 50%로 고정한다(그 아래로 플레이어 목록 등이 이어지고, 화면을 넘치면 페이지 전체가 아래로 스크롤됨). 채팅 메시지 자체가 그 50% 영역을 넘치면 채팅창 내부에서 위아래로 스크롤된다. 가로 모드·데스크톱에서는 채팅창이 남은 공간을 채우는 기존 방식(고정 50%가 아님) 유지
- [ ] **로비 흐름**: 로그인 후 로비 메뉴(게임설명·직업 설명·게임 시작·음향 설정·마이페이지 5버튼) → "게임 시작" → 모집 중인 공개방 목록(맨 위 "+ 새 방 만들기" 고정, 코드로 직접 입장도 가능) → 방 클릭 시 입장 → 방 안(플레이어 목록·준비 토글·방장 설정)
  - 게임설명/직업 설명/음향 설정/마이페이지 모달은 **좌상단 X 버튼**으로 닫는다
  - 공개방 목록·방 안 화면은 **좌상단 뒤로가기** 버튼으로 이전 화면으로 돌아간다. 방 안 화면의 방 코드 옆에는 직업 설명 버튼과 음향 설정 버튼(스피커 아이콘)도 둔다. 게임 화면에서도 직업 설명 버튼 옆에 동일한 음향 설정 경로를 제공한다
  - **마이페이지**: 프로필 사진·닉네임 변경(기존 지원)에 이어 **비밀번호 변경**(현재 비밀번호 확인 후 새 비밀번호로 교체) 지원. 이메일 변경은 재인증 절차가 필요해 범위 밖(추후)
  - 게임 종료 화면의 **"다시하기"**는 같은 방(공개방 목록에서는 자동으로 비공개 전환됨 — 방장이 다시 공개로 전환 가능)의 준비 단계로 돌아가고, **"로비로"**는 방을 나가 로비 메뉴로 돌아간다
  - **로비(방 대기중) 채팅**: 방 안 화면에서도 자유롭게 채팅 가능(게임 전용 페이즈/타이머 요소 없이 단순 채팅). 게임이 시작되면 채팅 로그가 초기화된다
- [ ] **본인 캐릭터/진영 상시 표시**: 게임 화면에 배정된 캐릭터와 진영을 게임 내내 확인할 수 있어야 한다(투항 버튼 근처). 캐릭터 배정(game:role)은 서버가 게임 시작 시 딱 1회만 보내는 정보라, 클라이언트가 이 이벤트를 놓치면 게임 내내 복구할 방법이 없다 — 소켓 리스너는 게임 화면이 아니라 로그인 이후 항상 마운트돼 있는 최상위 라우터에 등록해야 한다
- [ ] **투항하기 버튼**
  - 클릭 시 확인 모달: "정말로 포기하시겠습니까?" 예/아니오
  - **팀 동시 투항 방식**: 최초로 투항을 누른 시점부터 30초 카운트 시작 → 30초 내에 같은 팀 생존자 전원이 투항을 누르면 게임 종료(상대 팀 승리) → 30초가 지나도 전원 동의가 안 되면 투항 진행 종료(게임 계속)
  - **선 진영 투항은 생존 중립도 함께 동의해야 완료된다** (중립은 선 진영 승리에 편승하므로, 8번 섹션과 동일한 원리). 중립은 진행 중인 선 진영 투항에 동참만 가능하고 스스로 투항을 시작할 수는 없음. 악 진영 투항은 악 진영 생존자만 대상
  - 투항 진행 중이라는 사실이 상대 팀에게 노출되지 않도록 처리
- [ ] **악 팀 전용 버튼 (P버튼)**: 투항 버튼 옆 "원 안에 P" 아이콘. 클릭 시:
  - 사용자 본인 즉시 사망 처리
  - 해당 낮의 투표 단계를 스킵
  - 바로 밤 페이즈로 전환
  - (확인 모달 필요 여부는 투항 버튼과 동일하게 적용할지 별도 검토)
- [x] **도중에 나가기 버튼 (전 진영 공용)**: 위 P버튼과는 별개로, 실사정으로 게임을 지속하기 어려운
      플레이어가 진영 무관하게 즉시 이탈할 수 있는 버튼. 확인 모달("정말 게임을 나가시겠어요? 즉시
      사망 처리되며 되돌릴 수 없어요") 후 클릭 시:
  - 본인 즉시 사망 처리 — 단 길동무·유서 등 사망 확정 트리거는 발동하지 않는다(사망이 아니라
    이탈이므로). 조언자였다면 승계 절차 없이 즉시 파기(정순 고정)
  - 현재 진행 중이던 낮/밤 페이즈는 그대로 유지된 채 계속 진행된다(P버튼과 달리 낮 투표를
    강제 스킵하거나 밤으로 전환하지 않음) — 다만 이 이탈로 승리 조건이 즉시 성립하면 게임 종료
  - 나간 사람은 방 로스터(다른 플레이어 화면의 이름 표시)에는 남아 있지만 본인 화면만 로비로

## 7. 발언 순서 결정 로직 — "조언자 출마" 시스템

**첫날 아침 (조언자 선출)** — 4번 섹션의 밤 0(게임 시작 직후 첫 밤)이 끝난 뒤 진행:
1. 조언자 출마 버튼 표시 (7초) — 원하는 유저는 이 시간 안에 출마 신청
2. 출마자 개인별 어필 발언 (각 20초) — **출마한 유저들 중 배정 번호 오름차순(앞 번호부터 정순)으로 진행**
3. 전체 토론 (50초) — **출마자만 채팅 가능. 출마하지 않은 유저는 관전만 가능(입력 잠금)**
4. 조언자 선출 투표 (7초) — **출마한 유저에게는 투표권 없음**
5. 최다 득표자가 조언자로 확정
6. 확정 직후, 조언자에게 그날 발언 방향(정순/역순) 선택 시간 부여 (5초) — **첫날은 그 전에 밤이
   없어 이 시간이 유일한 선택 기회다.** 선택하면 타이머를 기다리지 않고 곧바로 개인 발언으로
   진행, 5초가 그냥 지나면 기본값(정순)으로 개인 발언이 시작된다

**조언자 규칙:**
- 조언자는 **방울**(무당의 무구)을 상징물로 가짐. 플레이어 목록에서는 조언자로 선출된 생존자의 프로필 왼쪽에 주황색 지팡이 아이콘(🪄)을 표시하고, 조언자가 사망하면(승계·파기 처리와 무관하게 그 시점부터) 즉시 사라진다
- 조언자의 발언 순서는 매일 **제일 마지막**
- 매 아침, 조언자가 자신의 앞뒤 번호를 기준으로 **역순 / 정순** 중 그날의 발언 방향을 결정 —
  첫날은 조언자 확정 직후(위 6번), 둘째 날 이후로는 밤 선 진영 스킬 시간(goodSkills)에 선택
- **선출 동표 처리**: 최다 득표가 동률이면 해당 최다득표자들만 후보로 하여 재투표 → 재투표에서도 동표면 최다득표자 중 **무작위 선정**

**조언자 사망 시 (사망 확정 트리거, 10초):**
- 죽기 전 두 가지 중 선택:
  - **승계**: 생존자 중 번호를 지목해 방울(조언자 역할)을 넘겨줌
  - **파기(방울 깨뜨리기)**: 조언자 역할 소멸 → 이후 발언 순서는 앞번호부터 정순으로 고정 진행
- **10초 내 미선택 시 자동 파기(소멸)** 처리

## 8. 승리 조건

- **악 진영 승리**: 선 진영 전원 탈락 **또는** 중립 진영 전원 탈락(선 진영 생존자 수와 무관하게 즉시) **또는** 선 진영 전원이 항복 투표
- **선 진영 승리**: 악 진영 전원 탈락 **또는** 악 진영 전원이 항복 투표
- **중립 승리**: 선 진영 승리 조건과 동일 — 악 진영 전원 처형(탈락) 시점에 중립 진영이 1명 이상 생존해 있으면 함께 승리
- **동시 전멸 우선순위**: 중립 전멸과 동시에 악 진영도 전멸하면(예: 사자의 명부로 묶여 있던 악·중립이 함께 죽는 경우) 중립 전멸 규칙보다 "악 전원 탈락 → 선 승리"가 우선한다(이길 악 진영 자체가 없으므로)
- [ ] 항복(투항)에 의한 승리 조건은 **일차(day count)와 무관하게 언제든 성립** — 기존 "4일차 이후"라는 제한 삭제. 탈락에 의한 승리 조건도 동일하게 일차 제한 없음

   REST는 Authorization 헤더로, Socket.io는 핸드셰이크 auth 페이로드로 실어 보낸다.
   client/server가 서로 다른 배포 도메인(Render 서브도메인)이라 크로스사이트 쿠키(SameSite=None)가

   쿠키 대신 토큰 방식으로 확정함
